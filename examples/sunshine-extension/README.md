# Combined Pi + Sunshine extension example

Zip this directory and import it from Sunshine's Extensions page.

The package contains:

- a standard Pi command (`/sunshine-example`);
- a native card above Sunshine's composer;
- an extension-owned native page in the conversation drawer;
- a WebView using the JavaScript action bridge;
- persistent extension state and Android host calls.

See `docs/SUNSHINE_EXTENSIONS.md` for the complete API.
